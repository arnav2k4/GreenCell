# Voltage Data Visualization and Analysis

This project performs data visualization and analysis on voltage
and timestamp data.

## Features

- Import voltage and timestamp data using Pandas
- Plot voltage against timestamp
- Generate 1000-value moving average
- Generate 5000-value moving average
- Generate 5-day moving average
- Detect local peaks
- Detect local lows
- Identify instances where voltage falls below 20
- Detect downward slope acceleration in downward cycles

## Technologies Used

- Python
- Pandas
- Matplotlib
- SciPy
